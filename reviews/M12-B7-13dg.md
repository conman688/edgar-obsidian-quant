### Where bugs are most likely
- The legacy regexes: event-date formats, rows 11/13 laid out across table cells, and a row
  number read as shares (guarded by a lookahead on "CHECK" and "%").
- Holder identity is the header's `FILED BY`.
  - Group members filing one joint filing count once.
  - Members filing separately count once each, so one block of shares can count more than
    once. The note says so.
- The 3-year rule (`STAKE_MAX_AGE_DAYS`) is a judgment, not an SEC rule.
  - A founder's unchanged 13D stake that is never amended drops out after 3 years.
  - 13D needs an amendment only for a material change. 13G needed a yearly one for changes
    before 2024, and a quarterly one since.
- `pending_filings` path choice: a filing whose subject is not priced is fetched under the
  filer's path. It is the same submission.
- `ingest 13dg` re-indexes the last two quarters on every run. Older quarters are indexed once.

    `holders_13g = 0`. This is the live DB after migration 14 until someone runs the manual

  - The same applies outside the loaded coverage:

  - Report 0 only where the data covers as_of: the 13D index covers the quarter, and as_of

  - Have the note say "not loaded" in that case.

### C2. A legacy row number after the shares heading is read as the share count
- Severity: low (stored value only; `shares` is not read by `stakes_sql`, the screen or the
  vault)
- Where: src/ingestion/sched13.py:126-127 (`_SHARES`)
- Evidence: the lookahead `(?!\s*(?:CHECK|%))` only stops a number followed directly by
  CHECK. When row 11 is empty, "PERSON 12. CHECK BOX" reads 12, because the "." stands between
  the number and CHECK. Backtracking can also read "1" out of "12 CHECK".
  - Real data: 106 legacy stakes have shares exactly 11, 11 have 12 and 34 have 1.
  - The schema says shares is "NULL when the cover page could not be read".
- Test:
  ```python
  def test_a_row_number_after_the_shares_heading_is_not_read_as_shares():
      doc = ("<TEXT>CUSIP No. 037833100 (1) NAMES OF REPORTING PERSONS FUND LP "
             "11 AGGREGATE AMOUNT BENEFICIALLY OWNED BY EACH REPORTING PERSON 12. CHECK BOX IF THE AGGREGATE "
             "AMOUNT IN ROW (11) EXCLUDES CERTAIN SHARES [ ] 13 PERCENT OF CLASS REPRESENTED BY AMOUNT IN ROW (11) "
             "7.5% 14 TYPE OF REPORTING PERSON PN</TEXT>")
      r = s13._parse_text(doc)
      assert r["pct"] == 7.5
      assert r["shares"] is None
  ```
